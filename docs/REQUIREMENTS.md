# REQUIREMENTS
## FNR
- System will allow an applicant to submit an application
- System will allow an applicant to upload their details 
- System will allow many users to be onboarded using csv or json
- System will implement row level validation of user details
- System will verify user identity with NIN/BVN

##NFNR
- System will not show values of users NIN/BVN in logs/responses
- System db schema versions will be saved as migrations
- System API will have proper documentation
- System will hash passwords
